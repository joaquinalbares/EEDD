## EJERCICIO 01:  Clasificación de lenguajes de programación en Markdown

### Objetivos
* Practicar la creación y el formateo de tablas complejas usando la sintaxis de **Markdown**.
* Analizar y categorizar los lenguajes de programación según sus características técnicas y ámbito de aplicación.

---

### Enunciado

Debes crear un documento en Markdown que contenga una **única tabla comparativa** organizada con los **15 lenguajes de programación más comunes**:

1. Python
2. JavaScript
3. Java
4. C#
5. SQL
6. C
7. TypeScript
8. PHP
9. Swift
10. Kotlin
11. Ruby
12. Rust
13. R 

---

### Requisitos de la tabla

La tabla debe incluir exactamente las siguientes **6 columnas**:

1. **Lenguaje**: Nombre del lenguaje de programación.
2. **Tipado**: Indicar si es *Estático* o *Dínámico*, y si es *Fuerte* o *Débil* (ej. *Dinámico / Fuerte*).
3. **Paradigma**: Indicar su enfoque principal (ej. *Orientado a Objetos*, *Multiparadigma*, *Funcional*, *Declarativo*).
4. **Nivel de Abstracción**: Clasificar entre *Alto nivel*, *Medio nivel* o *Bajo nivel*.
5. **Uso**: Indicar dónde se utiliza principalmente (ej. *Desarrollo Web Backend*, *Frontend*, *Ciencia de Datos*, *Sistemas/Embebidos*, *Móvil iOS/Android*).
6. **EJECUCIÓN**: Especificar si el código se ejecuta mediante *Compilador*, *Interpretado* o *JIT / Bytecode*.
