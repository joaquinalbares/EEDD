# UT 02: ENTORNOS INTEGRADOS DE DESARROLLO (IDE)

---

## 1. CONCEPTO Y FUNCIONES DE UN ENTORNO INTEGRADO DE DESARROLLO (IDE)

Un **Entorno Integrado de Desarrollo** (IDE, *Integrated Development Environment*) es una aplicación software que proporciona un conjunto consolidado de herramientas para facilitar y optimizar el ciclo de vida de creación de programas informáticos.

### Funciones Principales de un IDE
1. **Edición de código fuente avanzada:** Editores de texto inteligentes orientados a lenguajes específicos.
2. **Gestión de proyectos:** Organización jerárquica de ficheros, librerías, dependencias y recursos.
3. **Automatización de compilación y construcción (*Build Automation*):** Invocación de compiladores, enlazadores y herramientas de empaquetado mediante un solo clic o atajo.
4. **Depuración (*Debugging*):** Detección e inspección de errores en tiempo de ejecución de manera gráfica.
5. **Generación de ejecutables y despliegue:** Empaquetado final de aplicaciones (ej. archivos `.exe`, `.jar`, `.war`).
6. **Integración con sistemas externos:** Conexión con control de versiones (Git), analizadores estáticos de código y gestores de bases de datos.

## 2. TIPOS DE ENTORNOS DE DESARROLLO Y SUS CARACTERÍSTICAS
*(Atiende a los Criterios de Evaluación a y g)*

### Clasificación Según su Licencia (CE a)
* **Entornos de Desarrollo Libres / Open Source:**
  * Distribuidos bajo licencias de código abierto (GPL, Apache, MIT).
  * Permiten su uso, modificación y redistribución de forma gratuita sin restricciones comerciales.
  * *Ejemplos:* Eclipse, NetBeans, VSCodium, KDevelop.
* **Entornos de Desarrollo Propietarios / Comerciales:**
  * Desarrollados por empresas bajo licencias de pago o de suscripción.
  * Suelen ofrecer versiones comunitarias (*Community Edition*) con funcionalidades reducidas y versiones comerciales (*Ultimate/Enterprise*) con soporte oficial avanzado.
  * *Ejemplos:* IntelliJ IDEA (Ultimate), Microsoft Visual Studio (Professional/Enterprise), CLion, RAD Studio.

### Clasificación Según la Soporte de Lenguajes
* **IDE Monolenguaje / Especializado:** Diseñado para un único lenguaje o ecosistema específico (ej. PyCharm para Python, Xcode para Swift/Objective-C).
* **IDE Multilenguaje / Políglota:** Diseñado para trabajar con múltiples lenguajes mediante el uso de plugins y extensiones (ej. Eclipse, VS Code, NetBeans).

### Características Comunes y Específicas de Diversos IDEs (CE g)

| Entorno de Desarrollo | Licencia | Lenguajes Principales | Características Comunes | Características Específicas |
| :--- | :--- | :--- | :--- | :--- |
| **Eclipse** | Libre (EPL) | Java, C/C++, PHP | Editor avanzado, gestión de proyectos, depuración, sistema de plugins | Arquitectura basada en la plataforma *OSGi*, gran consumo de memoria RAM |
| **IntelliJ IDEA** | Mixta (Community / Propietaria) | Java, Kotlin, Scala, Python | Autocompletado inteligente, refactorización, integraciones VCS | Análisis estático de código en tiempo real de alta precisión, autocompletado con IA |
| **Visual Studio Code** | Libre (Core MIT) / Propietario (Binario MS) | Políglota (Python, JS, C++, Java) | Formateo, sintaxis, terminal integrada, extensiones | Ligero (basado en Electron), arquitectura centrada en ficheros/carpetas más que en proyectos rígidos |
| **Microsoft Visual Studio** | Propietaria | C#, C++, VB.NET, F# | Asistentes gráficos, depuración avanzada, diseñador UI | Diseñadores WYSIWYG integrados para desarrollo en Windows (WPF, .NET MAUI), compilador MSVC nativo |

## 3. INSTALACIÓN Y USO BÁSICO DE UN ENTORNO DE DESARROLLO
*(Atiende al Criterio de Evaluación a)*

### Instalación de un IDE (CE a)
El proceso de instalación de un entorno de desarrollo varía según la plataforma y la naturaleza del IDE:
* **Instalación mediante Instaladores Ejecutables / Binarios:** Archivos `.exe` (Windows), `.dmg` (macOS) o `.deb`/`.rpm` (Linux).
* **Instalación mediante Gestores de Paquetes / Cajas de Herramientas:** Empleo de aplicaciones centralizadas como *JetBrains Toolbox* o comandos del sistema (`sudo apt install`, `winget`, `brew`).
* **Verificación de Requisitos Previos:** Muchos IDEs basados en Java (como Eclipse o NetBeans) requieren la presencia previa de un **JDK (Java Development Kit)** en el sistema operativo.

### Paneles, Vistas y Espacios de Trabajo (*Workspaces*)
* **Workspace / Espacio de Trabajo:** Directorio del sistema donde el IDE almacena los proyectos, configuraciones y metadatos del usuario.
* **Vistas (*Views*):** Paneles individuales que muestran información específica (ej. Explorador de archivos, Consola, Estructura de clases/Outline, Lista de errores).
* **Perspectivas (*Perspectives*):** Disposiciones preconfiguradas de paneles orientadas a una tarea concreta (ej. Perspectiva de *Desarrollo*, Perspectiva de *Depuración*, Perspectiva de *Bases de Datos*).

### Gestión de Proyectos e Incorporación de Elementos
1. **Uso de Asistentes (*Wizards*):** Herramientas guiadas para la creación de proyectos definiendo el nombre, la ubicación, la versión del SDK/JDK y las plantillas iniciales.
2. **Creación de Proyectos:** Estructuración de directorios estándar (ej. `src/` para código fuente, `lib/` para bibliotecas externas, `bin/` o `target/` para archivos compilados).
3. **Incorporación de Elementos:** Adición de paquetes, módulos, clases, interfaces, archivos de configuración (XML, JSON, YAML) y recursos multimedia.

### Edición de Código, Formateo y Asistencia a la Programación
* **Resaltado de Sintaxis (*Syntax Highlighting*):** Coloreado diferenciado de palabras reservadas, variables, cadenas de texto y comentarios.
* **Autocompletado de Código (*IntelliSense / Code Completion*):** Sugerencia de métodos, clases y variables disponibles al escribir.
* **Formateo e Indentación Automática:** Aplicación de reglas de estilo de código mediante atajos de teclado (ej. `Ctrl+Shift+F` en Eclipse, `Ctrl+Alt+L` en IntelliJ).
* **Importación y Exportación:** Herramientas para importar proyectos existentes desde el disco o sistemas VCS, así como exportar proyectos a archivos comprimidos (`.zip`), archivos ejecutables (`.jar`) o plantillas.

### Compilación, Detección de Errores y Ejecución
1. **Compilación en Segundo Plano:** Detección en tiempo real de errores sintácticos marcados con subrayados rojos antes de la compilación explícita.
2. **Consola y Panel de Problemas:** Lista ordenada de advertencias (*Warnings*) y errores de compilación (*Errors*).
3. **Generación de Ejecutables y Ejecución:** Invocación de la ejecución directa dentro del IDE mediante botones de reproducción (*Run*) o generación del binario final en el disco.

## 4. INSTALACIÓN Y GESTIÓN DE MÓDULOS, PLUGINS Y EXTENSIONES
*(Atiende al Criterio de Evaluación b)*

Los entornos de desarrollo modernos cuentan con una arquitectura modular extensible basada en **plugins**, **módulos** o **extensiones** que permiten añadir soporte para nuevos lenguajes, frameworks o herramientas.


```

[ Núcleo del IDE (Core) ] ───┬───► [ Plugin: Soporte Git ]
├───► [ Plugin: Analizador SonarLint ]
└───► [ Plugin: Framework Spring Boot ]

```

### Gestión del Ciclo de Vida de un Módulo (CE b)
1. **Acceso al Catálogo / Marketplace:** Utilización del gestor interno del IDE (ej. *Eclipse Marketplace*, *IntelliJ Plugins Repository*, *VS Code Extensions*).
2. **Añadir / Instalar Módulos:** Búsqueda en el repositorio oficial o instalación manual desde archivos locales (ej. archivos `.vsix` en VS Code o `.jar`/`.zip` en Eclipse).
3. **Configurar / Activar / Desactivar:** Inhabilitar temporalmente plugins sin necesidad de desinstalarlos para optimizar el rendimiento del entorno.
4. **Eliminar / Desinstalar Módulos:** Borrado completo del módulo del sistema para liberar espacio o resolver conflictos entre extensiones.

## 5. PERSONALIZACIÓN, AUTOMATIZACIÓN Y CONFIGURACIÓN DE ACTUALIZACIONES
*(Atiende a los Criterios de Evaluación c y d)*

### Personalización del Entorno (CE c)
* **Temas Visuales y Aspecto:** Modificación de esquemas de color (temas claros/oscuros) y fuentes tipográficas con soporte de ligaduras (ej. *Fira Code*, *JetBrains Mono*).
* **Atajos de Teclado (*Keymaps*):** Reasignación personalizada de combinaciones de teclas o emulación de esquemas de otros editores (ej. emulación de atajos de Vim en Eclipse).
* **Plantillas de Código (*Code Snippets / Live Templates*):** Creación de abreviaturas que expanden bloques de código repetitivos automáticamente (ej. escribir `psvm` para generar `public static void main(String[] args)`).

### Automatización de Tareas (CE c)
* **Acciones al Guardar (*Save Actions*):** Configuración para que el IDE formatee el código, organice los `import` y elimine código muerto automáticamente cada vez que se guarda un archivo.
* **Integración con Herramientas de Construcción (*Build Tools*):** Automatización de compilación, ejecución de pruebas unitarias y empaquetado mediante scripts de **Maven**, **Gradle**, **Ant** o **Make**.
* **Macros:** Grabación e invocación de secuencias repetitivas de comandos de edición.

### Configuración del Sistema de Actualización (CE d)
* **Canales de Actualización:**
  * *Stable (Estable):* Versiones probadas y recomendadas para entornos de producción.
  * *EAP (Early Access Program) / Beta / Insiders:* Versiones preliminares con las últimas novedades pero posibles inestabilidades.
* **Modos de Actualización:**
  * **Automática:** Descarga e instalación transparente en segundo plano.
  * **Notificación / Manual:** El IDE comprueba periódicamente si existen nuevas versiones de la plataforma o de los plugins instalados y solicita confirmación al usuario.
* **Configuración de Proxy y Red:** Parámetros de red necesarios para acceder a las actualizaciones en entornos corporativos o educativos restringidos.

## 6. GENERACIÓN MULTILENGUAJE Y MULTI-IDE
*(Atiende a los Criterios de Evaluación e y f)*

### Generación de Ejecutables Multilenguaje en un Mismo IDE (CE e)
Un IDE políglota correctamente configurado mediante módulos y herramientas de compilación permite desarrollar y generar ejecutables para diferentes lenguajes de programación desde una única interfaz.

```
                    ┌───► [ Código C++ ] ───► Compilador GCC ───► Ejecutable (.exe/bin)
[ Mismo IDE ] ──────┼───► [ Código Java ] ──► Compilador Javac ─► Ejecutable (.jar)
(ej. VS Code)       └───► [ Código Python ] ─► PyInstaller ──────► Ejecutable (.exe)
```

* **Ejemplo práctico:** Configuración de VS Code o Eclipse para compilar un programa en **C++** (usando el compilador `g++`) y, simultáneamente, un proyecto en **Java** (usando el `JDK`) o un script compilado a ejecutable nativo en **Python** (usando `PyInstaller`).

### Generación de Ejecutables Multi-IDE a partir del Mismo Código Fuente (CE f)
Dado un mismo conjunto de archivos de código fuente, es posible importar dicho proyecto en distintos entornos de desarrollo y obtener un ejecutable funcional en cada uno de ellos, demostrando la independencia del código respecto al entorno.


```
                            ┌───► [ IDE 1: Eclipse ] ────────┐
[ Mismo Código Fuente ] ────┼───► [ IDE 2: IntelliJ IDEA ] ──┼───► [ Ejecutable Idéntico ]
                            └───► [ IDE 3: NetBeans ] ───────┘
```

* **Estándar de Proyecto Independiente:** El uso de herramientas de construcción neutras como **Maven** o **Gradle** permite que un proyecto creado en un IDE (ej. NetBeans) pueda abrirse, compilarse y empaquetarse en otro IDE (ej. IntelliJ IDEA o Eclipse) sin incompatibilidades.

## 7. ACCESO A DOCUMENTACIÓN Y AYUDA INTEGRADA

Los entornos de desarrollo facilitan la consulta de documentación técnica sin necesidad de abandonar el entorno de trabajo:

1. **Documentación Javadoc / Docstrings Integrada:** Muestra de ventanas emergentes (*tooltips*) con la descripción, parámetros y retorno de clases y métodos al pasar el cursor sobre ellos.
2. **Navegación al Código Fuente:** Atajos para saltar directamente a la declaración o definición de una función o clase (ej. `F3` o `Ctrl + Clic`).
3. **Ayudas de Contexto e Inspección (*Quick Fix / Intentions*):** Propuesta de correcciones automáticas ante errores mediante combinaciones de teclas (ej. `Ctrl + 1` en Eclipse, `Alt + Enter` en IntelliJ).
4. **Documentación Oficial del IDE:** Acceso directo desde el menú de ayuda (*Help*) a manuales de usuario, guías de atajos de teclado y páginas de soporte técnico.
