Práctica UT03P01: Instalación de Eclipse IDE, Gestión con Maven y Depuración con JUnit 5 en Xubuntu

Verificación del Entorno

Asegúrate de tener instalado el Kit de Desarrollo de Java (JDK) en tu sistema Xubuntu antes de iniciar Eclipse:
Terminal
sudo apt update && sudo apt install default-jdk -y
java -version

🛠️ Desarrollo Paso a Paso

Paso 1: Instalación de Eclipse IDE mediante Tarball (.tar.gz)

  1. Descargar la versión oficial de Eclipse: Abre el navegador o utiliza la terminal para descargar el paquete comprimido de Eclipse IDE for Java Developers:

    Terminal - Descarga de Eclipse
    cd ~/Descargas
wget -c "https://www.eclipse.org/downloads/download.php?file=/technology/epp/downloads/release/2024-03/R/eclipse-java-2024-03-R-linux-gtk-x86_64.tar.gz&r=1" -O eclipse-java.tar.gz

  2. Extraer el archivo en el directorio personal o /opt:

    Terminal - Extracción
    tar -xvf eclipse-java.tar.gz -C ~/

  3. Lanzar Eclipse IDE: Navega al directorio extraído y ejecuta el binario:

    Terminal - Ejecución
    ~/eclipse/eclipse &

  4. Seleccionar el Espacio de Trabajo (Workspace): Al iniciar, selecciona el directorio por defecto /home/usuario/eclipse-workspace y haz clic en Launch.

Paso 2: Creación de un Proyecto Java con Apache Maven

  1. Crear nuevo proyecto Maven:
  2. En el menú superior de Eclipse, selecciona File ➔ New ➔ Maven Project.

  3. Marca la casilla Create a simple project (skip archetype selection) y haz clic en Next.

  4. Definir las coordenadas de Maven:

  5. Group Id: es.iesalbares.ed
  6. Artifact Id: calculadora-maven
  7. Version: 1.0.0-SNAPSHOT

  8. Haz clic en Finish.

  9. Configurar las dependencias de JUnit 5 (pom.xml): Abre el archivo pom.xml generado en la raíz del proyecto y añade la dependencia de JUnit 5 dentro de la etiqueta <dependencies>:

    pom.xml
    <project xmlns="http://maven.apache.org/POM/4.0.0" 
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" 
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>
  <groupId>es.iesalbares.ed</groupId>
  <artifactId>calculadora-maven</artifactId>
  <version>1.0.0-SNAPSHOT</version>

  <properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>

  <dependencies>
    <!-- Dependencia oficial de JUnit 5 (Jupiter) -->
    <dependency>
      <groupId>org.junit.jupiter</groupId>
      <artifactId>junit-jupiter</artifactId>
      <version>5.10.2</version>
      <scope>test</scope>
    </dependency>
  </dependencies>
</project>

Guarda el archivo (Ctrl + S). Maven descargará automáticamente las librerías necesarias.

Paso 3: Desarrollo de la Lógica Orientada a Objetos

  1. Despliega la carpeta src/main/java.
  2. Haz clic derecho sobre src/main/java ➔ New ➔ Class.
  3. Package: es.iesalbares.ed.modelo

  4. Name: Calculadora

  5. Escribe el siguiente código:

src/main/java/es/iesalbares/ed/modelo/Calculadora.java
package es.iesalbares.ed.modelo;

public class Calculadora {

    public double sumar(double a, double b) {
        return a + b;
    }

    public double dividir(double a, double b) {
        if (b == 0) {
            throw new IllegalArgumentException("No se puede dividir por cero");
        }
        return a / b;
    }

    public int calcularFactorial(int n) {
        if (n < 0) {
            throw new IllegalArgumentException("El número debe ser no negativo");
        }
        int resultado = 1;
        for (int i = 1; i <= n; i++) {
            resultado *= i; // Punto clave para inspección en depuración
        }
        return resultado;
    }
}

Paso 4: Implementación de Pruebas Unitarias con JUnit 5

  1. Despliega la carpeta src/test/java.
  2. Clic derecho sobre src/test/java ➔ New ➔ JUnit Test Case.
  3. Selecciona New JUnit Jupiter test (JUnit 5).
  4. Package: es.iesalbares.ed.modelo
  5. Name: CalculadoraTest

  6. Class under test: es.iesalbares.ed.modelo.Calculadora

  7. Implementa los casos de prueba:

src/test/java/es/iesalbares/ed/modelo/CalculadoraTest.java
package es.iesalbares.ed.modelo;

import static org.junit.jupiter.api.Assertions.*;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;

class CalculadoraTest {

    private Calculadora calc;

    @BeforeEach
    void setUp() {
        calc = new Calculadora();
    }

    @Test
    @DisplayName("Suma exitosa de dos números")
    void testSumar() {
        assertEquals(5.0, calc.sumar(2.0, 3.0), "2 + 3 debe ser 5");
    }

    @Test
    @DisplayName("Excepción al dividir por cero")
    void testDividirPorCero() {
        assertThrows(IllegalArgumentException.class, () -> calc.dividir(10.0, 0.0));
    }

    @Test
    @DisplayName("Cálculo del factorial de 5")
    void testFactorial() {
        assertEquals(120, calc.calcularFactorial(5), "Factorial de 5 debe ser 120");
    }
}
  1. Ejecutar el Test:
  2. Haz clic derecho sobre CalculadoraTest.java ➔ Run As ➔ JUnit Test.
  3. Comprueba que se abre la vista JUnit con la barra verde que confirma la superación de todas las pruebas.

Paso 5: Depuración paso a paso e Inspección de Variables

  1. Establecer un Punto de Ruptura (Breakpoint):
  2. Abre Calculadora.java.

  3. Haz doble clic sobre el margen izquierdo (junto al número de línea) en la instrucción dentro del bucle del factorial: 

    resultado *= i;

  4. Aparecerá una bola azul indicando que el punto de ruptura está activo.

  5. Iniciar la sesión de depuración:

  6. Abre CalculadoraTest.java.
  7. Haz clic derecho ➔ Debug As ➔ JUnit Test.

  8. Eclipse solicitará cambiar a la Perspectiva de Depuración (Debug Perspective). Haz clic en Switch.

  9. Inspección de variables y control de flujo:

  10. Observa la vista Variables (esquina superior derecha). Identifica los valores en tiempo real de i, n y resultado.
  11. Utiliza las teclas de control de depuración para avanzar en la ejecución:
  12. F5 (Step Into): Entra dentro del método llamado.
  13. F6 (Step Over): Ejecuta la línea actual y pasa a la siguiente.

  14. F8 (Resume): Continúa la ejecución hasta el siguiente punto de ruptura o final del programa.

  15. Haz avanzar el bucle iterativamente con F6 u F8 observando cómo cambia el valor de la variable resultado en cada paso.
